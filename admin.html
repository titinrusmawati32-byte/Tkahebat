Pengaturan Sistem & Integrasi

Konfigurasi URL Google Apps Script Web App dan parameter sistem.

Koneksi Google Apps Script API

Aplikasi ini beroperasi menggunakan Google Apps Script sebagai serverless backend dan Google Spreadsheet sebagai basis data. Masukkan URL Web App yang telah dideploy dengan akses "Anyone" (Siapa saja).

Jika dikosongkan, sistem berjalan otomatis dalam Mode Demo Offline dengan data bawaan tersimpan di memori browser.

Panduan Penyiapan Database

  • Buka file Code.gs di Google Apps Script pada Spreadsheet Anda.
  • Jalankan fungsi setupDatabase() satu kali untuk inisialisasi sheet otomatis.
  • Deploy sebagai Web App dengan:
    • Execute as: Me (email Anda)
    • Who has access: Anyone (Siapa saja)
  • Salin URL Web App yang diakhiri /exec ke kolom di sebelah kiri.
  • File gambar diunggah langsung ke folder Google Drive otomatis melalui modal Pratinjau Soal.
